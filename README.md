# ZeckClips

<img src="APP/app/logo.svg" width="160" alt="Logo de ZeckClips">

Convierte vídeos largos en clips verticales para TikTok, Reels y Shorts, con subtítulos automáticos y títulos con IA.

**Descargar:** instaladores para Windows, macOS (Intel y Apple Silicon) y Linux en [Releases](../../releases/latest).

El código está en [`APP/`](APP) y la guía completa en [`APP/README.md`](APP/README.md).
